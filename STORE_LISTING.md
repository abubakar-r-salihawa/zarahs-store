# Android testing and draft listing

Name: Zarah's Store

Short description: Shop perfumes, kitchen essentials and fashion from independent boutiques.

Discover fragrances, kitchen essentials, fashion and accessories from independent boutiques. Browse products, select available sizes and save your cart. Sign in to place an order request and track it in My Orders. Choose whether to send each boutique its order details using WhatsApp. Confirm payment, delivery charges and return conditions with the seller before paying. Placing an order request does not collect payment or guarantee delivery.

## Android acceptance testing

For each check record device, Android version, date, result and any screenshot. Use a designated test account. Coordinate real orders and messages with the owner first.

- Install the debug APK, cold start, close and reopen.
- Browse all three boutiques; verify current prices and availability.
- Select sizes, change quantities, restart and confirm cart persistence.
- Verify email login and Google browser sign-in return to the app.
- Test failed checkout and retry; cart remains and no duplicate order is created.
- Check multi-boutique totals and the correct seller for each WhatsApp link.
- Confirm My Orders shows only the current customer's orders; sign out.
- Submit a deletion request once; confirm it appears in the owner queue. This does not delete the account.
- Check back navigation, keyboard, large text and small-screen layout.
- Turn off connectivity and confirm clear feedback, without false success.
